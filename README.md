# tidy for Windows

맥용 tidy(`../unnamed`)를 복사해 만든 윈도우 전용 프로젝트입니다. 맥 버전과는 따로 관리합니다.
`docs/` 폴더는 맥 버전 기준으로 쓴 문서이고, 윈도우에서 달라지는 점은 이 파일에 정리했습니다.

## 설치 파일 만들기

윈도우 PC에서 [Node.js](https://nodejs.org), [Rust](https://rustup.rs)(Visual Studio C++ Build Tools 포함)를 설치한 뒤 이 폴더에서 실행합니다.

```powershell
npm install -g pnpm
pnpm install
pnpm exec tauri build
```

설치 파일은 `src-tauri\target\release\bundle\nsis\` 에 만들어집니다.
GitHub에 올리면 `.github/workflows/build-windows.yml` 이 같은 빌드를 자동으로 하고 설치 파일을 Artifacts에 올립니다.

## 맥 버전과 다른 점

| 기능 | 윈도우 동작 |
|---|---|
| 아이콘 배치 | 탐색기의 바탕화면 뷰(`IFolderView`)로 옮깁니다. 정리할 때 '아이콘 자동 정렬'과 '아이콘을 그리드에 맞춤'을 끕니다. |
| 앱으로 분류 | `.exe`, `.url`, `.appref-ms`, 프로그램을 여는 바로 가기, 스토어 앱 바로 가기, 휴지통 같은 시스템 아이콘 |
| 바로 가기 | 폴더 바로 가기는 폴더로, 문서 바로 가기는 파일로 분류합니다. |
| 범위 미리보기 | 배경화면과 아이콘이 놓일 자리만 표시합니다. 실제 아이콘 이미지는 보이지 않습니다. 단색 배경은 표시되지 않습니다. |
| 위젯 | 윈도우에는 바탕화면 위젯이 없어 비워 둘 자리도 없습니다. |
| 정렬 순서 | Finder 색상 태그가 없어 이름순입니다. |
| 파일 이름 | `< > " \| ? *`, 점이나 공백으로 끝나는 이름, `CON`·`NUL` 같은 예약 이름은 쓸 수 없습니다. |
| 권한 | 화면 기록 권한이 필요 없습니다. |
| 공용 바탕화면 | `C:\Users\Public\Desktop` 항목은 자리만 옮기고, 파일 이동은 관리자 권한이 필요할 수 있습니다. |

## 테스트 상태

맥에서 윈도우 대상 컴파일 검사와 공통 로직 테스트만 통과했습니다. 실제 윈도우에서는 아직 실행해 보지 않았습니다.
처음 실행할 때 아이콘 위치, 화면 배율(125%, 150%), 듀얼 모니터, 파일 이동과 되돌리기를 확인해 주세요.
