# 릴리스 체크리스트

## 판정: No-Go

- [x] macOS 개발 환경에서 TypeScript 검사, Vite 빌드, Rust 테스트
- [x] 앱의 AI/desktop/watcher 미지원 범위를 명시
- [x] 6단계 규칙 저장 및 opt-in 새 파일 후보 watcher 구현
- [ ] 강제 종료 후 작업 이력과 실제 파일 경로를 대조하는 복구 절차/UI
- [ ] Windows 빌드/파일 작업 capability 검증 (현재 파일 이동은 안전상 미지원)
- [ ] UI 자동화, 성능/접근성 확인, 다중 모니터/긴 경로/디스크 부족/재시작 시나리오
- [ ] 패키징 및 코드 서명 설정 검증 (서명 자격 증명은 저장하지 않음)
- [ ] 의존성 라이선스/취약점 점검 결과 기록

현재 실제 테스트 환경은 macOS 개발 환경이며 OS 버전 및 서명 패키지는 검증하지 않았습니다. 개인 실제 폴더를 대상으로 한 파괴적 테스트는 실행하지 않았습니다. 릴리스 전 작업 이력 복구, Windows 지원 정책, UI 자동화 미검증 6단계 감시 경로를 해결해야 합니다.
