# 데스크톱 capability

| 기능 | macOS | Windows |
|---|---|---|
| 데스크톱 항목 아이콘 정렬 | 아이콘/파일 범위를 따로 지정하고 Finder Apple Event로 좌표 배치 | 미지원 |
| 아이콘 좌표를 직접 지정 | 지정한 두 범위 안에서 Finder를 통해 가능 | 미지원 |
| 선택한 파일을 새 폴더에 모으기 | 네이티브 파일 선택 후 바탕화면 새 폴더에 복사. 원본 보존 | Tauri picker 경로는 코드상 가능하지만 검증 안 됨 |

정리 범위 미리보기는 실제 바탕화면을 층별로 다시 그립니다. 시스템 창 목록(CGWindowList)에서 배경화면 창, Finder 바탕화면 아이콘 층, 알림 센터의 데스크톱 위젯 창을 찾아 각각 `screencapture -l`로 캡처하므로 다른 앱 창은 보이지 않고 tidy 창을 숨기지도 않습니다. 앱을 열 때, 15초 이상 지나 앱으로 돌아올 때, 정렬 직후에 다시 불러옵니다. 배경화면·아이콘·위젯 이미지는 화면 기록 권한이 필요하고, 위젯 위치(테두리)는 권한 없이도 표시됩니다. 정렬할 때 위젯 위치를 다시 읽어, 범위 안에서 위젯(과 약간의 여백)에 걸리는 자리는 비워 두고 나머지 자리에 아이콘을 배치합니다. 자리가 모자라면 위젯이 차지한 면적만큼 더 큰 범위를 권장합니다.

미리보기에서 앱 아이콘 범위와 폴더·파일 범위를 각각 이동·크기 조절할 수 있으며 두 범위는 겹치면 적용되지 않고 앱에 저장됩니다. 정렬 버튼은 앱(앱을 가리키는 별칭 포함)을 앱 아이콘 범위에, 그 외 항목은 폴더를 먼저, 이어서 파일을 새 행부터 폴더·파일 범위에 배치합니다. 아이콘 간격과 정렬 위치는 앱 아이콘 범위와 폴더·파일 범위에 각각 따로 정합니다. 정렬 위치(왼쪽·가운데·오른쪽)를 고르면 각 범위 안에서 아이콘 묶음과 덜 찬 줄이 그쪽에 붙고, 아이콘은 범위 가장자리 밖으로 나가지 않습니다. 아이콘 간격은 자동(범위 전체에 고르게 퍼뜨림)과 아주 좁게·좁게·보통·넓게·아주 넓게 5단계 중에서 고릅니다. 단계를 고르면 범위 위쪽부터 그 간격(가로×세로 84×88pt부터 158×154pt까지)의 격자로 채웁니다. 미리보기에는 현재 범위·간격으로 정렬했을 때 각 항목이 놓일 자리가 테두리로 표시됩니다(아무것도 옮기지 않음). Finder 색상 태그(태그 이름이 아닌 색상 번호로 판단하므로 시스템 언어와 무관)와 이름을 항목 순서에 반영합니다. 일부 항목을 Finder가 옮기지 못하면 나머지는 계속 배치하고 실패한 항목 이름을 알려 줍니다. 아이콘 위치는 달라질 수 있지만 파일/폴더 경로, 이름, 내용, 색상 레이블은 변경하지 않습니다. 바탕화면 폴더의 숨김 항목(점으로 시작하거나 Finder 숨김 플래그가 있는 `Icon\r` 등)은 건너뜁니다. 주 화면 기준이며 첫 사용 시 macOS가 Finder 제어 권한을 요청할 수 있습니다.

파일 옮기기는 파일 선택 창에서 고른 일반 파일만 대상으로 합니다. 옮길 곳은 바탕화면에 새로 만드는 폴더 또는 폴더 선택 창에서 고른 이미 있는 폴더입니다. 옮기기 전에 파일마다 새 이름을 정할 수 있습니다(확장자는 고정, `.tar.gz` 같은 이중 확장자 포함). 여러 개를 "이름 + 번호"로 한 번에 바꿀 수 있고, 빈 이름·`/ \ :`·점으로 시작·255바이트 초과·같은 이름(대소문자 무시)은 옮기기 전에 막습니다. 옮길 곳에 같은 이름이 있으면 덮어쓰지 않고 `(2)` 같은 번호를 붙이며, 이미 그 폴더에 같은 이름으로 있는 파일은 그대로 둡니다. 새 폴더 이름이 겹치면 폴더 생성 자체를 거부하고, 하나도 옮기지 못하면 빈 새 폴더를 남기지 않습니다. 결과 화면과 작업 이력에서 원래 위치로 되돌릴 수 있습니다.
