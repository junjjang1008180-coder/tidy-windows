# 로컬 분석 상태

현재 빌드에는 AI 모델, OCR, 문서 텍스트 추출기가 없습니다. Rust `AnalysisProvider` 경계는 `UnavailableProvider`로 연결되어 있으며, 상태 조회는 `unavailable-no-model-installed`를 반환합니다. 이미지/문서 입력 형식, 크기 한도, 분석 시간 한도는 지원 항목이 없어 정의하지 않습니다. 네트워크 호출은 하지 않습니다.

모델 출처·라이선스·용량·플랫폼 호환성을 검증해 번들한 모델이 없으므로 포함을 보류했습니다. 앱은 분석 추천이나 mock 결과를 AI 결과처럼 만들지 않습니다. 향후 실제 provider 추가 시 포맷/크기/취소/타임아웃/오류/저장 정책을 별도 검증해야 합니다.
