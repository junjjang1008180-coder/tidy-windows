# 구조

- `src/ui`: React + TypeScript 인터페이스와 Tauri command/event 사용
- `src-tauri/src/lib.rs`: Rust 명령 경계, 경로 검증, 스캔/중복/파일 작업, SQLite 기록
- 앱 데이터 SQLite: 메타데이터 인덱스, 작업 계획/상태. 파일 내용은 저장하지 않습니다.
- 선택 폴더는 네이티브 대화상자를 통해 Rust 상태에 등록됩니다. 순회는 링크를 따라가지 않습니다.
- 중복 탐지: 크기 사전 필터, 1 MiB 스트리밍 SHA-256, 해시 일치 후보 64 KiB 바이트 비교. 결과 해시는 영구 캐시하지 않습니다.
- 파일 이동: plan ID는 현재 세션에서 만든 계획만 승인 가능합니다. 경로 양 끝의 디렉터리를 no-follow 디스크립터로 열고, 지원 플랫폼에서 원자적 no-replace rename을 수행합니다. SHA-256으로 계획 이후 콘텐츠 변경도 감지합니다. 이력과 파일시스템 변경은 원자적 공동 트랜잭션이 아닙니다.
- 분석 provider 경계는 현재 항상 `UnavailableProvider`입니다. 네트워크 호출 및 분석 결과 생성이 없습니다.
- 데스크톱 기능은 폴더 내 분류 수량 기반 안내만 하며, 화면/아이콘 API를 호출하지 않습니다.
- 사용자 분류/파일명/레이아웃 선호는 localStorage에 저장합니다. 선택 루트 watcher는 기본 꺼짐이며 앱 내에서 30초 간격 metadata scan으로 새 후보를 알립니다. 앱 시작 시 자동 watcher는 생성하지 않습니다.
