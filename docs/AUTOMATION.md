# 사용자 규칙 및 자동 감지

확장자별 분류, 파일명 템플릿(`{name}`, `{date}`, `{ext}`), 레이아웃 선호(minimal/productivity/categories/projects)를 로컬 webview 저장소에 저장합니다. 규칙은 화면 표시와 새 이름 제안에만 사용되며 파일 이동은 3단계 미리보기/별도 승인 후에만 실행됩니다. 규칙 화면에서 JSON 내보내기(네이티브 저장 대화상자)와 저장값 삭제가 가능합니다. 규칙에 적은 새 분류 이름은 파일 목록 필터 탭에 추가됩니다.

폴더 감시는 기본 꺼짐이며 사용자가 고른 현재 루트에 대해 앱 실행 중 30초 간격으로 메타데이터 스캔을 수행합니다. 감시를 시작할 때 있던 파일은 후보가 되지 않으며, 그 뒤 새로 생긴 파일만 두 번 연속 감지 주기에서 크기/수정 시각이 같을 때 후보로 표시합니다. 감시 스캔은 백그라운드에서 끝까지 읽은 뒤 목록을 한 번에 바꿔 화면이 깜빡이지 않습니다. 수동 스캔·폴더 선택은 진행 중인 감시 스캔이 끝난 뒤 시작합니다. `.part`, `.tmp`, `.crdownload`, `.download`, `~$` 이름은 후보에서 제외됩니다. 감시는 일시 중지할 수 있고 앱을 종료하면 중지되며 재시작 후 자동으로 켜지지 않습니다.

파일 내용은 검사하지 않으며 후보로 자동 이동/이름 변경/삭제하지 않습니다. 감시 오류는 화면에 알립니다. 규칙은 localStorage, 후보와 감시 상태는 메모리에만 보존됩니다. UI timer 경로는 자동화 테스트 환경이 없어 실제 30초 간격 통합 검증이 남아 있습니다.
