# 개인정보와 로컬 데이터

스캔 인덱스와 작업 이력은 Tauri 앱 데이터 디렉터리의 SQLite에 저장됩니다. 경로·이름·확장자·크기·수정 시각·분류 및 파일 작업 상태가 포함됩니다. 중복 검사 때 파일 내용을 로컬에서 읽어 해시와 바이트를 비교하지만 해시는 영구 저장하지 않습니다. AI 분석, OCR, 외부 전송 및 원격 분석은 없습니다.

사용자 확장자/파일명/레이아웃 규칙은 앱 webview localStorage에 저장되며 규칙 화면에서 JSON 내보내거나 삭제할 수 있습니다. 새 파일 감시 설정과 후보는 메모리에만 있으며 감시는 기본 꺼짐, 앱 실행 중 선택 루트만 30초 간격으로 스캔합니다. 후보 경로는 UI에서만 표시하고 파일을 자동 변경하지 않습니다.

앱 데이터 디렉터리를 제거하면 SQLite 인덱스와 이력이 제거됩니다. 실행 중인 파일 이동 결과는 파일 시스템에 남을 수 있으며 interrupted 작업을 실제 경로와 대조/복구하는 UI는 없습니다. localStorage 규칙 삭제는 규칙 화면의 삭제 버튼으로 수행합니다.
