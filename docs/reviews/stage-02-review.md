# 2단계 독립 검수

검수 범위: `find_duplicates`, SHA-256/바이트 비교, 진행 이벤트 및 중복 UI. 코드 수정 없이 Rust 임시 fixture 테스트, TypeScript 검사와 Vite 빌드를 실행했습니다.

## 발견 사항

### Major — 읽기/변경 오류가 조용히 누락됨

- 위치: `src-tauri/src/lib.rs:98-100,107-110,118`
- WalkDir/metadata 오류, 해시 중 변경·읽기 오류, 바이트 비교 오류가 모두 후보 제외로 처리됩니다. UI는 검색이 정상 완료됐다고 표시해 중복 후보가 누락된 사실을 알 수 없습니다.
- 영향/재현: 선택 폴더 내 읽기 권한이 없는 파일 또는 검색 중 변경되는 파일을 두면 그 항목이 결과에 포함되지 않고 경고도 없습니다.
- 권장 조치: 경로를 기록하지 않는 skipped 카운트를 반환하고 결과 화면에 불완전 검색 경고를 표시합니다.

### Major — 취소가 최종 바이트 비교 중 반영되지 않음

- 위치: `src-tauri/src/lib.rs:64-75,114-120`
- 크기가 같고 SHA-256이 같은 후보를 재검증하는 `same_bytes`는 취소 토큰을 받지 않습니다. 매우 큰 중복 파일 쌍은 읽기 전용이지만 취소 후에도 끝까지 비교할 수 있습니다.
- 영향/재현: 큰 동일 파일 두 개를 만든 뒤 해시 직후 취소하면 비교 루프가 끝날 때까지 UI가 취소되지 않습니다.
- 권장 조치: 비교 루프에도 취소 토큰과 진행 콜백을 전달하고, 취소 상태를 결과와 별도로 반환합니다.

### Major — 해시/비교 사이 변경 경합

- 위치: `src-tauri/src/lib.rs:114-128`
- 안정성 메타데이터 검사는 해시 종료 시점에만 합니다. 그 후 바이트 비교 전에 파일이 바뀌면 새 내용끼리 같은 파일인지 비교하면서 이전 해시 문자열을 그룹에 넣을 수 있습니다.
- 권장 조치: 동등성 비교 후 메타데이터 안정성을 다시 확인하고, 변경된 후보는 그룹에서 제외해 경고합니다.

## 검증 결과

- 통과: `cargo test --offline` 7개 테스트 (동일/상이 바이트, 빈 파일, 취소 및 기존 Foundation 테스트).
- 통과: `tsc --noEmit --pretty`, Vite 프로덕션 빌드.
- 구현 확인: SHA-256은 1 MiB 고정 버퍼로 스트리밍되고 캐시는 없습니다. 해시/경로 외부 전송이나 자동 정리는 없습니다.
- 미검증: 권한 오류, 실제 동시 파일 변경 경합, 대용량 바이트 비교 취소, Windows 실행.
