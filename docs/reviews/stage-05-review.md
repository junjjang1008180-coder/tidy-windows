# 5단계 독립 검수

- 현재 UI의 “정돈 추천”은 사용자가 선택한 폴더에서 이미 읽은 파일 종류별 수량을 보여주는 규칙 기반 안내입니다. 데스크톱 폴더 자동 탐색이나 아이콘 배치라고 주장하지 않습니다.
- `docs/DESKTOP-CAPABILITIES.md`는 macOS 좌표 제어 미지원, Windows 미검증, 모니터 정보 미지원, Windows 파일 이동 미지원으로 구분합니다.
- 승인 없는 파일 이동 및 사용 빈도 추적 코드는 없습니다. 실제 좌표/OS adapter 또는 화면 배치 복구 기능은 구현되지 않았습니다.
- 검증: TypeScript 타입 검사 및 Vite 빌드 통과. OS별 실기능/다중 모니터 테스트는 미실행.

**판정: 추천 전용의 제한된 안내로 통과. 요청된 데스크톱 레이아웃 적용 기능은 미지원이며 이를 자동화로 표시하지 않습니다.**
