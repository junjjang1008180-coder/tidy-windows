# 6단계 독립 검수

- `src/ui/App.tsx`는 확장자 분류, `{name}/{date}/{ext}` 파일명 템플릿, 레이아웃 선호를 localStorage에 저장하며 JSON 내보내기/삭제 조작을 제공합니다.
- watcher는 기본 꺼짐이고 사용자가 선택한 현재 루트에서만 30초마다 Rust metadata scan을 호출합니다. 새 경로를 두 번의 연속 scan에서 같은 size/mtime으로 관찰하면 후보 알림을 추가합니다. 임시 다운로드 확장자와 `~$` 파일을 제외하고 후보를 자동 변경하지 않습니다. 종료하면 watcher는 재개되지 않습니다.
- UI 조작은 저장 상태 외의 개인 데이터를 외부로 전송하지 않습니다. localStorage 규칙, 메모리 후보로 저장 위치가 문서화되어 있습니다.

## Major — UI timer 경로 자동 검증 부재

- 재현: 앱에서 실제 watcher를 켜고 30초 주기 두 차례를 관찰해야 합니다. 단위/UI 테스트 runner가 없어 이 작업을 자동 재현하지 못했습니다.
- 영향: pause/resume, 중복 이벤트, 오류/재시작, 부분 다운로드 안정화는 실행 환경에서 자동 회귀 검증되지 않았습니다.
- 검증: TypeScript 검사 및 Vite 빌드 통과. Rust scan 경계 테스트 통과. UI timer 통합 테스트는 미실행.

**판정: 기능은 구현, 자동화 검증 조건부. 릴리스 전 watcher UI 테스트 필요.**
