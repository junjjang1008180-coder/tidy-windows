# 안전과 개인정보

- 기본 스캔은 사용자가 대화상자에서 고른 canonical 루트 안의 메타데이터만 읽습니다. 심볼릭 링크와 숨김 항목은 제외합니다. Rust에서 선택 루트와 대조합니다.
- 중복 탐지는 파일 내용을 로컬에서 읽어 크기 후보화, 스트리밍 SHA-256, 바이트 비교를 합니다. 외부로 보내지 않고 해시 캐시도 없습니다.
- 파일 작업 계획은 Rust에서 경로/충돌을 검증하고 승인 직전 다시 확인합니다. 크기/수정 시각/SHA-256이 달라지면 거절합니다.
- 사용자가 지정한 아이콘 범위에는 앱과 폴더를, 파일 범위에는 일반 파일을 Finder Apple Event로 배치합니다. 겹치는 범위는 허용하지 않습니다. 변경하는 것은 아이콘 위치뿐이며 파일/폴더 경로·이름·내용·색상 레이블은 바꾸지 않습니다. macOS 자동화 권한이 필요합니다.
- 파일 옮기기는 네이티브 파일 선택창에서 고른 파일 목록과 일치하는 파일만, 바탕화면에 새로 만든 폴더 또는 네이티브 폴더 선택창에서 고른 폴더로만 옮깁니다(둘 다 Rust에서 대조). 같은 볼륨은 덮어쓰기 없는 원자적 rename(RENAME_EXCL)으로 옮깁니다. 다른 볼륨은 검증된 복사(같은 볼륨이면 clonefile, 아니면 복사하며 SHA-256 계산 후 복사본 대조)를 마친 뒤, 원본 크기·수정 시각이 그대로일 때만 원본을 지웁니다. 각 이동은 작업 이력에 기록되며, 되돌릴 때는 옮겨진 파일의 크기·나노초 수정 시각이 기록과 같고 원래 자리가 비어 있을 때만 원위치합니다.
- macOS/Linux 파일 이동 기능은 선택된 폴더 안에서만 실행하고 no-follow 디렉터리 핸들 및 no-replace 원자 rename을 사용합니다. Windows 파일 이동은 지원하지 않습니다.
- 작업 이력에는 작업한 폴더(root)를 함께 저장하므로 다른 폴더를 선택한 뒤에도 되돌릴 수 있습니다. 실행 전 이력에 "실행 중"을 기록하지 못하면 파일을 건드리지 않고, 실행 도중 이력 저장이 실패하면 남은 항목을 계속 처리한 뒤 해당 항목에 경고를 표시합니다. 같은 폴더 안에서 대소문자만 바꾸는 이름 변경은 같은 파일(inode)일 때만 허용합니다.
- 작업 이력은 전체 경로를 저장합니다. DB는 Tauri 앱 데이터에 있고 UI에서 이력 삭제 기능은 없습니다.
- 배포 빌드는 CSP(`default-src 'self'`, 이미지는 data: 허용)를 적용합니다. 개발 모드(devCsp)는 적용하지 않습니다.
- AI 모델, OCR, 네트워크 분석, telemetry는 없습니다. 사용자 규칙과 opt-in 폴더 감시는 별도 기능이며 감지로 자동 파일 변경을 하지 않습니다.
