# 알려진 제한

- 실제 AI 모델, OCR, 텍스트 추출 및 로컬 콘텐츠 분석 없음.
- 데스크톱 범위별 아이콘 배치는 macOS Finder의 주 화면을 기준으로 합니다. Windows와 보조 모니터 범위 설정은 지원하지 않습니다.
- opt-in watcher는 UI 30초 폴링이며 OS native watcher가 아닙니다. 타이머/이벤트 경로 UI 자동화 테스트가 없습니다. 감지 후보만 표시합니다.
- Windows 빌드 오류(숨김 속성 import)는 고쳤지만 Windows 빌드 자체는 검증하지 않았습니다. Windows 파일 이동/이름 변경 미지원. Linux 및 다양한 Unix 파일 시스템 미검증.
- rename과 SQLite 상태 기록이 공동 트랜잭션이 아니며, 강제 종료 후 파일 경로 확인 및 사용자가 할 복구 안내 UI가 없습니다.
- 작업 이력에 경로를 저장하며 UI 이력 삭제/보존 기간 설정을 제공하지 않습니다.
- 성능, 접근성, 디스크 부족, 대규모 폴더, 긴 경로, 설치 패키지/서명은 검증하지 않았습니다.
