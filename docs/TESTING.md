# 검증

## 실제 검사 명령

- `cargo test --offline --manifest-path src-tauri/Cargo.toml`: Rust 단위 테스트. 분류, SQLite, 취소, 숨김/링크 fixture, 정확 중복/빈 파일, 작업 미리보기/충돌/경로 이탈/오래된 상태/undo 충돌, 분석 provider 상태, 작업 폴더 기준 되돌리기, 이력 저장 실패 시 계속 처리, 인덱스 교체, Finder 태그 색상 해석, 대소문자만 바꾸는 이름 변경, 바탕화면 배치 영역 계산, AppleScript 이스케이프, 새 폴더 이름 검증을 확인합니다 (21개).
- TypeScript 타입 검사와 Vite 빌드: 번들 Node 런타임 사용.
- Windows 빌드, UI 자동화, 코드 서명/패키징, 초대형 실제 폴더, 디스크 부족, 강제 종료 복구는 검증하지 않았습니다.

## 수동 시나리오

1. 임시 폴더의 파일·숨김 파일·하위 폴더·링크로 스캔 경계를 확인합니다.
2. 같은 크기의 다른 파일, 동일 바이트 파일, 빈 파일로 중복 판정을 확인합니다.
3. 작업 계획 생성 전후 파일 무변경, 승인 시 충돌/경로 이탈 차단을 확인합니다.
4. 승인 계획 후 파일 내용을 변경하면 실행을 거부하는지 확인합니다.
5. 성공 작업 undo 및 원래 위치 충돌 처리를 확인합니다.
6. AI 비활성, 데스크톱 추천 전용, watcher 기본 꺼짐/opt-in, 새 파일 안정화, pause/resume 및 규칙 내보내기/삭제를 확인합니다. watcher의 timer 경로는 별도 UI 자동화로 아직 검증하지 않았습니다.
