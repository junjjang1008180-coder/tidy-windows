# 제품 개요

모아는 사용자가 선택한 폴더의 파일 메타데이터를 읽기 전용으로 목록화하는 로컬 우선 데스크톱 앱입니다.

## 1단계 기능

- 폴더 대화상자, 하위 폴더 순회, 파일명 검색과 카테고리 필터
- 이름, 확장자, 파일 크기, 수정 시각 표시
- 문서·사진·영상·압축·기타 확장자 규칙 분류
- 진행 중 취소와 로컬 SQLite 인덱스

## 범위 밖

이동/이름 변경/삭제, 중복 정리, 사진 내용 분석, 외부 AI, 데스크톱 아이콘 제어는 제공하지 않습니다. 생성 시각은 플랫폼 간 의미가 다르므로 현재 표시하지 않습니다.
